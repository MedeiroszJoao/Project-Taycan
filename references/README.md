# Reference materials

Subdirectories catalog battery, motor, inverter, drivetrain, thermal, and image assets.
Keep metadata, source URL, copyright/license status, applicability to MY2022/Taycan 4S standard battery, and evidence confidence here.
Do not copy original Porsche imagery or workshop manuals into this public repository without authorization.
Use `references/image_catalog/` for image hashes, component labels and source links, not unreviewed original media.
